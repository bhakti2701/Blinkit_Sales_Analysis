# Blinkit Sales Dashboard & Business Insights

## Project Overview
This project analyzes Blinkit sales data to uncover business insights using Power BI and Python. The goal is to understand sales trends, customer preferences, and outlet performance.

## Key Features
- Interactive Power BI dashboard
- Sales performance analysis
- Customer rating insights
- Product category analysis
- Regional revenue trends

## Tools & Technologies
- Power BI (DAX, Data Modeling, Visualization)
- Python (Pandas, NumPy)
- Excel

## Dashboard Preview
![Dashboard](https://github.com/bhakti2701/Blinkit_Sales_Analysis/blob/main/images/blinkitdashboard_preview.png)

## Data Cleaning (Python)
- Handled missing values
- Removed duplicates
- Standardized data formats

## Key Business Insights
- Tier 3 locations generate highest sales
- Fruits & Snacks are top-selling categories
- Medium outlets perform best
- Customer ratings impact sales trends
